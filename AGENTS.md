# AGENTS.md

## Commands
- Package manager: **Bun** (`bun.lock` present). Do not use npm/yarn/pnpm.
- `bun run dev` — dev server at localhost:3000 (via `next dev` + `initOpenNextCloudflareForDev()`)
- `bun run build` — Cloudflare Workers build (`opennextjs-cloudflare build` → `.open-next/`, calls `bun run build:next` internally)
- `bun run build:next` — raw Next.js build only (`.next/`)
- `bun run preview` — `opennextjs-cloudflare build && opennextjs-cloudflare preview` (workerd)
- `bun run deploy` — `opennextjs-cloudflare build && opennextjs-cloudflare deploy` (Workers)
- `bun run lint` — `biome check`
- `bun run format` — `biome format --write`
- No test runner configured. Verify with `bun run lint` (and `bun run build` only with permission).

## Forbidden
- Never run `bun run dev`, `bun run build`, or `next start` without explicit user permission.

## Stack
- Next.js 16.2.9 (App Router) + React 19.2.4. Check `node_modules/next/dist/docs/` before assuming APIs.
- Tailwind CSS v4 via `@import "tailwindcss"` in `src/app/globals.css`; theme in `@theme inline` there; PostCSS uses `@tailwindcss/postcss`; no `tailwind.config.*`.
- Biome for lint/format (not ESLint/Prettier). 2-space indent.

## Build quirks
- `next.config.ts`: **no** `output: "export"` / `distDir` — Workers build needs server output (`.next/server/`). Keep `images.unoptimized: true`, `reactCompiler: false`, plus `initOpenNextCloudflareForDev()` for local dev.
- `open-next.config.ts`: `buildCommand: "bun run build:next"` breaks recursion when `build` is `opennextjs-cloudflare build`.
- `wrangler.jsonc`: `main: ".open-next/worker.js"`, `assets.directory: ".open-next/assets"` — do not change; generated by OpenNext.
- Cloudflare Workers Builds: Build cmd `npx opennextjs-cloudflare build`, Deploy cmd `npx opennextjs-cloudflare deploy` (or `bun run build` now also works via buildCommand indirection). `npx wrangler deploy` auto-delegates to OpenNext when `open-next.config.ts` present, but requires `.open-next/` to exist first.
- `next-env.d.ts` is generated — do not edit.

## Layout
- Entrypoints: `src/app/page.tsx`, `src/app/layout.tsx`
- Alias `@/*` → `src/*` (`tsconfig.json`)
- Static assets: `public/`
